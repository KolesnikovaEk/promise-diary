## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Для проверки готовой версии приложения и офлайн работы:

```bash
npm run build
npm run preview
```

# Дневник обещаний

Веб-приложение для учета обещаний и сроков их выполнения

Приложение позволяет:
- создавать и редактировать дела;
- отмечать дела как выполненные;
- искать дела по названию и описанию;
- просматривать дела за выбранный день, период или месяц;
- сортировать дела по датам;
- фильтровать дела по статусу;
- добавлять и удалять комментарии;
- работать в офлайн режиме.


# Принятые решения

- Приложение написано на JavaScript 
- Использованы React, Vite
- Данные хранятся в IndexedDB
